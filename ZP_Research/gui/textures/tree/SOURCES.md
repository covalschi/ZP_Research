# Задники вікна дерева досліджень — походження й ліцензія

Дата: 2026-08-23. Сім файлів `tree_bg_<фракція>.paa` — по одному на фракцію
(`Factions.json → TreeBackgroundImage`).

## З чого зроблено

Кожен задник — це **згенероване тло** (глухий графіт + тонований радіальний підсвіт кольором
фракції + плівкове зерно + віньєтка), у центр якого вкладено **нашивку відповідного
угруповання** зі S.T.A.L.K.E.R.-вікі, приглушену до ~60 % прозорості й знебарвлену.

| файл | фракція | джерело нашивки (stalker.fandom.com) |
|---|---|---|
| `tree_bg_ecolog.paa` | Вчені | `File:S2 patch clean scientists.png` |
| `tree_bg_clearsky.paa` | Чисте небо | `File:Patch s2 clear sky.png` |
| `tree_bg_duty.paa` | Долг | `File:S2 patch clean duty.png` |
| `tree_bg_freedom.paa` | Воля | `File:S2 patch clean freedom.png` |

| `tree_bg_bandit.paa` | Бандити | `File:Patch s2 bandits.png` |

Генератор: `scripts/make-tree-bg.py` (полотно 1024×1024, стеля яскравості 110/255).

## Два обмеження, які визначили вигляд

1. **Рушій НЕ приглушує цю картинку.** Перевірено живцем: ні `color` у розмітці, ні
   `SetColor`, ні `SetAlpha` на `TreeBgImage` не діють (див. коментар у `ZP_TreeMenu.c`).
   Тому затемнення впечене у файл: без нього білі підписи вузлів на тлі не читаються.
2. **Картинку розтягують без збереження пропорцій** (`stretch mode stretch_w_h`, віджет
   700×558). Полотно квадратне (PAA вимагає сторони — степені двійки), тож емблему
   намальовано заздалегідь стиснутою по горизонталі на 1/1.2545 — після розтягу вона стає
   круглою.

## Ліцензія — увага власника

Нашивки угруповань — інтелектуальна власність **GSC Game World** (S.T.A.L.K.E.R.), узята з
фанатської вікі. Для приватного/громадського сервера це звична практика (сам модпак сервера
вже возить похідні від GSC ассети), але **для публікації мода у Workshop це питання до
власника**. Замінити просто: покласти свої `.paa` з тими самими іменами або вписати інші
шляхи в `Factions.json → TreeBackgroundImage`; порожній рядок повертає загальний
`Settings.TreeBackgroundImage`.

Якщо потрібен варіант **без чужої IP** — генератор уміє малювати ті самі тла без нашивки
(силует, кольорове тонування й зерно лишаються); скажіть, і буде зібрано.
