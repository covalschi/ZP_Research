# ZP Research — веб-редактор конфігів

WYSIWYG веб-редактор JSON-конфігів мода `ZP_Research` для DayZ (Stalker RP). Працює
офлайн, без бекенду; збирається в **один самодостатній файл** `dist/index.html`.

## Команди

- `npm test` — тести (vitest).
- `npm run build` — збірка в `dist/index.html` (єдиний файл, комітиться в git).
